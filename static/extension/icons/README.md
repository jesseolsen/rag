# Extension Icons

You need to create simple icons for the extension. Here are the sizes needed:

- icon16.png - 16x16 pixels
- icon48.png - 48x48 pixels  
- icon128.png - 128x128 pixels

## Quick solution

Use any image editing tool or online tool to create a simple icon (e.g., a resume/document icon in blue/purple gradient colors to match the Resume RAG branding).

For now, you can:
1. Use an existing PNG file from your system
2. Or create a simple SVG and convert to PNG
3. Or download free icon from flaticon.com

The extension will work without icons, but Chrome will show a generic placeholder.

## Recommended

A simple document/resume icon in these colors:
- Gradient: #667eea to #764ba2 (matches the app branding)
- Simple design, single color or two-tone
