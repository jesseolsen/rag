Form Filler Bookmarklet

This bookmarklet automatically fills job application forms with your resume data. Just drag the button below to your bookmarks bar.

How to create bookmark:

  • Chrome: Ctrl+Shift+B → Bookmark manager → Add bookmark → Paste code in URL
  • Firefox: Ctrl+Shift+B → Right-click → New Bookmark → Paste code in Location
  • Safari: Cmd+Y → + button → Paste code in Address field

Step 2: When on a job application page, click the bookmarklet. It will prompt for your resume ID on first use, then remember it.

The bookmarklet:

  • Detects form fields on the page
  • Matches fields to your resume data (name, email, phone, etc.)
  • Automatically fills matching fields
  • Highlights filled fields in yellow

The bookmarklet doesn't work on some sites

Some job sites use iframes or complex JavaScript frameworks that prevent automatic form filling. For these sites, the bookmarklet may not be able to access all fields. You can manually copy values from your resume.

How do I switch resumes?

Run this in your browser console: localStorage.removeItem('job_app_resume_id')
